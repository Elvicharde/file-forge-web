# FileForge Web

The official website for [FileForge](https://github.com/Elvicharde/file-forge-cli), a cross-platform CLI for common filesystem operations.

This repository contains the static landing page for the FileForge project.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript

No framework or build step is required.

## Development

Clone the repository and open `index.html` in a browser, or serve the directory using any static file server.
